# Code of Conduct

This project welcomes respectful, constructive technical collaboration
regardless of identity, background or experience.

## Expected behavior

- Engage professionally and give specific, evidence-based feedback.
- Respect others' time, differing opinions and reasonable constraints.
- Use synthetic examples; never publish passwords, real customer traffic,
  private information or credentials.
- Keep discussions relevant, constructive and reproducible.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, unwanted sexual attention,
doxxing, intimidation, deliberate disruption and malicious contributions
are not tolerated.

## Enforcement

Maintainers may moderate comments, issue warnings, or restrict participation
proportionately. Avoid posting sensitive allegations in public issues.
Request a private channel with a maintainer for conduct concerns. Security
vulnerabilities are reported separately under [SECURITY.md](SECURITY.md).
